Running a script

From a PowerShell terminal in the repo folder:

PS> cd Examples
PS> .\script-name.ps1

If Windows blocks it, allow scripts for just this session:

PS> Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
